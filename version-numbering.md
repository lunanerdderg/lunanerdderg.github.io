***How version numbering works in my programs:***

[`Major feature added (OR) Major code rewrite`] **.** [`Minor feature added (OR) Minor code rewrite (OR) Major bug fix`] **.** [`Minor bug fix (OR) Misc tiny change`]

They all begin at `1.0.0`. If a project is released in an early state, it will start at `pre-1.0.0`, then the number will be reset to `1.0.0` on the full release.

<sub>_So far, I have had no reason to implement Nightly Builds, but if I ever do, then `n#.#.#` will probably be what I use for them. (Also considering `n-#.#.#` or `nightly-#.#.#`. Whichever I choose will be consistent between ALL of my programs.)_</sub>
