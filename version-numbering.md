*How version numbering works in ALL of my programs:*

[`Major feature added (OR) Major code rewrite`] **.** [`Minor feature added (OR) Minor code rewrite (OR) Major bug fix`] **.** [`Minor bug fix (OR) Misc tiny change`]

They ALL begin at `1.0.0`. If a project is unfinished but functional, it will start at `pre-1.0.0`, then the number will be reset to `1.0.0` on the full release.

So far, I have had no reason to implement Nightly Builds, but if I ever do, then `pre-n1.0.0` will be used for them.
